## 对象与方法

- 图片根目录（下文路径均相对此目录）：`C:/Users/yzj123/AppData/Local/Temp/opencode/all-components-fixed-final`。
- 实际逐张使用 `read` 打开并真实查看原始 PNG：**30/30 张**；读取失败：0 张。检查每张全图，没有使用联系表或已有报告代替原图。

- 构建类型、实际 EXE 来源及渲染后端无法由这些图片确认；本报告不据此宣称交互行为或实际窗口验收通过。`opened` / `settled` 为证据文件名，不推断其间发生了何种操作。
