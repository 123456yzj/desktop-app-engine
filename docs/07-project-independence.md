# 项目边界

该仓库独立维护引擎源码、锁定依赖、协议文档、业务模板和打包工具。可视化编辑器作为独立制作端，通过 JSON 协议对接。

引擎库承载通用协议、编译器、运行时、组件、布局、服务和渲染器。多仓库构建工作台位于 `src/bin/vben-package/`，独立持有 SSH 仓库操作、构建计划、连接设置和业务界面生成。

构建产物默认位于 `target/`，也可通过 `CARGO_TARGET_DIR` 指定。交付应用位于打包参数指定的目录；用户日志、凭据和连接设置位于当前用户本地数据目录。开发不依赖其他工程的源码、工具链副本或历史构建产物。

运行与验证命令见 [README](../README.md)，应用打包规则见 [分发决策](06-packaging-decision.md)。
