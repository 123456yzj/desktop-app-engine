# 产品需求

## 最终目标

- 在低代码平台设计 Windows 应用界面。
- 自定义按钮、文本、表格等元素，并支持菜单、多页面和布局容器。
- 元素通过 SSH 查询服务器数据；按钮执行自定义命令。
- 输出可独立使用的 Windows 桌面应用，无需运行制作工具。
- 优先复用现成能力，减少重复开发。

## 当前范围

- 当前选择 Rust 实现应用描述引擎，复用 GUI 框架。
- 支持 JSON 描述、文本、输入框、按钮及行／列布局。
- 支持状态绑定、点击动作和结果更新。
- 固定 Windows 运行时配合同目录 app.json 分发，导出应用无需重新编译；内嵌示例保留为开发兜底。

## 后续范围

- SSH、查询解析、数据源、执行日志。
- 菜单、多页面、表格及复杂布局。
- 可视化编辑器和自动生成应用流程。

## 首个验收场景

输入名字 → 点击确认 → 显示“你好，名字”。

EXE 在没有编辑器、没有外部示例 JSON 的情况下能独立运行。
