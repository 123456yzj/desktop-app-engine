# 命令绑定

协议 0.2 的 `command` 动作在后台执行本机程序。参数可为固定字符串或绑定，工作目录相对应用目录解析；参数和输入状态使用动作开始时快照。程序执行、双流消费与日志位于 `src/services/command.rs`，调度和完成提交位于 `src/runtime/`。

同一结果 target 不允许重复启动。命令启动后继续执行后续动作步骤；任务结束后一次性提交结果，每条流保留前 16384 字节。实时预览和完整原始输出文件独立提供，见 [日志](19-runtime-logs.md)。

可选 `onComplete: "actionId"` 在结果写入后执行。成功、非零退出、启动失败和超时都触发完成动作；回调按命令声明作用域解析，不能要求 event 载荷。应用关闭后的取消结果不派发回调。

`parseJson` 可把命令 stdout 字符串解析到已声明状态，例如：

```json
{"type":"parseJson","target":"view","value":{"kind":"state","key":"job","path":"/stdout"}}
```

无效 JSON、类型或组件约束不匹配会保留旧 target，停止后续步骤。加载时只检查绑定字符串类型，不提前解析可能尚为空的 stdout。

默认超时 60 秒，不提供 stdin 交互。超时或关闭时终止直接子进程，不保证后代或远端进程退出；关闭最多等待完成消息 500ms。UTF-8 解码替换非法字节，其他编码需要外部程序自行配置。应用所需脚本或程序需单独分发或在客户机安装；`--check` 不执行命令，也不检查外部程序是否安装。

完整结构和结果字段见 [描述格式](05-description-format.md)。多仓库构建工作台使用独立业务控制器，见 [构建工作台](20-turbo-build.md)。
