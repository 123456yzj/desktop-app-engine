Log tooltip and manual scrolling fix - 2026-10-15
Package: exports/turbo-log-scroll-fix/vben-package/
SHA256: CDB31048E90D00A6155E94686413FB300B597207089982269A18E77D840DF2DE

Root causes:
- Styled text automatically showed its full content in a tooltip when it overflowed.
- The native host called scroll_to_end(logScroll) every frame while auto-scroll was enabled, overriding manual scrolling on subsequent frames.

Changes:
- Added strict optional boolean style.textOverflowTooltip (default behavior retained).
- Disabled overflow tooltips for workbench logOutput and logMetadata.
- Native renderer reports containers moved by wheel/scrollbar input during a draw.
- Host pauses auto-scroll after manual log movement; new output and description replacement retain position. Clicking auto-scroll again returns to the end and resumes following.
