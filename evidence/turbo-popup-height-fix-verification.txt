Dynamic select popup height fix - 2026-10-15
Package: exports/turbo-popup-height-fix/vben-package/
SHA256: 2BFF343E2ED99A567926B2F035BE46AF2F1A451733F425F16DA8B44957AACF2D

Root cause:
egui ComboBox popup Area retains its prior small size after rendering one loading/empty option. The internal ScrollArea maximum height does not override this remembered available size; its default 64px minimum permits only two full rows. The original test opened an already-populated list and missed this transition.

Fix:
Native select anchor and popup now explicitly size the ScrollArea minimum and maximum from up to ten current option rows. Popup placement chooses above/below using screen space. Selection, disabled options, open/change events, outside-click closure and Escape closure continue through native egui interaction.
